# V5.2.0 RC5 - in-game separator check (5 minutes)

Install RC5 MAIN (or ASI-ONLY) over RC4: the menu file and SWF are replaced.
Back up `Documents\The Witcher 3\dx12user.settings` first.

1. **Fresh menu:** Options > Mods > Ultimate Refined Tracing. All five headings (CPU, Path Tracing,
   Ray Tracing, Texture / Streaming, Frame Generation) show a white line on **both** sides, text centred.
2. **Scroll:** to the very bottom, back to the very top, three times (mouse wheel, then controller/keys).
   Both lines stay on every heading.
3. **Reopen:** close the menu, reopen it, scroll again. Restart the game, repeat step 2 once.
4. **Other pages first:** open the vanilla Graphics page (and another mod's page, e.g. Immersive World),
   scroll it, then open URT and repeat step 2. If a right line is missing ONLY after this, report which page.
5. **Settings:** change one URT row and back, then a vanilla graphics option and back. Texture Quality
   still shows your setting (e.g. Ultra+).
6. Optional (settings audit): with the game closed, search `dx12user.settings` for `UseHBIL`,
   `EnableAOSSSampling`, `EnableAOPretrace`, `RtRadianceScreenSpaceTrace`, `TextureInFlightCountBudget`.
   If you ever set those rows away from Native / Auto, note whether the file values changed.

Expected visual difference: the two faint unnamed divider lines inside Ray Tracing are gone.
