# Ultimate Refined Tracing V5.2.0 CURATED PRIVATE RC3 - gameplay acceptance

**PRIVATE TEST ONLY.** Offline passing tests and genuine Windows WCC compilation
are not proof of runtime stability or compatibility.

## Before installing

* Quit Witcher 3. Save copies of `Documents\The Witcher 3\dx12user.settings`
  and your private `UltimateRefinedTracing.settings` outside the game/Documents folder.
  Keep the protected V5.1.0 installer ZIP for rollback.
* Choose MAIN if you do not already have an ASI loader, otherwise ASI-ONLY.
  Do not delete another mod's `dinput8.dll` or damage SharedUtils mod/DLC.
* Replace RC2 with RC3; do not leave two URT installations enabled.

## In-game essentials

1. **Menu + exact choices:** Under Options > Mods > Ultimate Refined Tracing,
   confirm Master and Quick Presets first, and CPU / Path Tracing / Ray Tracing /
   Texture / Streaming / Frame Generation headers. The RT section retains
   two subtle separators. 45 controls, no second Advanced page.
2. **Separators after scrolling:** Check that BOTH white line segments flank
   each category title at initial open, after scrolling to bottom, back to top,
   menu close/reopen and full game restart. The old RC2 right-line drop is NOT
   confirmed fixed by offline checks. Report any recurrence with screenshot.
3. **Removed rows:** PT Scene Range and PT Texture Detail in Reflections and
   Bounces are gone. Texture Memory Budget and Texture Sharpness (Mip Bias) are
   gone. The sole Texture / Streaming control is **Textures Streamed at Once**.
   Existing Indirect-Light Compensation stays immediately below Hair Bounces.
4. **Native graphics settings integrity:** In the vanilla Graphics menu, set
   Texture Quality to Ultra+ and photograph/record relevant chosen settings.
   Check the same values after setting URT Master Off/On, after URT menu edits,
   after changing Textures Streamed at Once in a controlled test, and after
   game restart. Values must NOT silently change. File size must stay healthy;
   a SHA change alone can be a legitimate game save, so compare actual settings.
   Stop and restore V5.1.0 if Ultra+ becomes Low again.
5. **Save + renderer isolation:** Test one new Normal RT setting only in
   Normal RT, and PT Ambient Occlusion Quality only in PT. Reopen menu and
   restart; values persist. Master Off restores effective native behaviour;
   native graphics choices remain what you selected. Existing preset mappings
   and manual-edit auto-Off remain intact. Do not infer performance gains
   without comparable gameplay scenes.
6. **Compatibility + stability:** Check the original Game/Gwent Difficulty
   hotfix, Orange Hair Fix in PT and Normal RT, and Immersive World wind,
   grass/trampling and animations. Test a normal play session and review logs.
7. **Optional FG:** Keep Frame Generation: Keep Resources in Menus at
   Native/Auto for the first stability pass. Only later test this optional
   experiment, preserving NVIDIA App Recommended settings and monitoring
   menu-exit stutter, tearing and resource retention.
