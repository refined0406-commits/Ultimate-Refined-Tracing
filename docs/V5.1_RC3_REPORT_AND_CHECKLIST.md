# V5.1.0-rc3 (private): change report, offline results, gameplay checklist

## Changes vs V5.1.0-rc2
* **Removed entirely:**
  * RTGI: Performance Shading Rays Per Probe and RTGI: Quality Shading Rays Per Probe.
    * Their menu rows, the 12 related strings in every language (labels, tooltips, and the value names only these rows used) and their script handling are gone.
    * The runtime always leaves the game's own shading rays (native 32) untouched. A value saved by V4.x/V5.0/rc2 is ignored, never read, and cannot invalidate the other RTGI settings.
  * RTGI: Performance Console Probe Grid.
    * Its menu row, strings, script and runtime code are gone. The game's RTXGI tier and re-initialisation are never touched.
    * An rc2 saved value is ignored and never read.
* **Kept, unchanged:** RT Reflections: Local Lights, RT Shadows: Local Light Shadows, RT Shadows: Foliage Detail.

  | Quick Preset | Performance | Balanced | Extreme |
  |---|---|---|---|
  | Reflection Local Lights | Off | Off | Native / Auto |
  | Local Light Shadows | Off | 4 | Native / Auto |
  | Foliage Detail | Very Low | Low | Native / Auto |

* **RTGI Quick Presets** (identical for RTGI Quality and RTGI Performance; **bold** = changed in rc3):

  | | Performance | Balanced | Extreme |
  |---|---|---|---|
  | Primary Classification Rays | 32 | 64 | 128 |
  | Secondary Classification Rays | **12** (was 4) | **16** (was 12) | 32 |
  | Probe Classification Limit | 8192 | 65536 | 262144 |
  | AO Pretrace Quality | 1 | 2 | 4 |
  | Shading Frame Budget | 65536 | **262144** (was 196608) | 524288 |
  | Global Grid Probe Shading Limit | 4096 | 12288 | 32768 |
  | Secondary Grid Probe Shading Limit | 16384 | 49152 | 262144 |
  | Shading Rays Per Probe | removed (Native) | removed (Native) | removed (Native) |

  Every other preset assignment is unchanged.
