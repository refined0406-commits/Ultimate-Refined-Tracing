# V5.2.0 RC6 - in-game checklist (short)

Back up `Documents\The Witcher 3\dx12user.settings` first. Install RC6 MAIN (or ASI-ONLY) over RC5.

1. **Menu:** check that the headings appear in this order, with the white line on **both** sides of each:
   - CPU
   - Path Tracing
   - PT: Caustics
   - Ray Tracing
   - RTGI: Quality
   - RTGI: Performance
   - RT/PT: Shared
   - Textures / Rendering
   - Frame Generation

   Scroll to the bottom and back to the top three times, close and reopen the menu, and check again.
2. **Rows:**
   - PT: Scene Range is directly under PT: Ray-Traced Shadows.
   - PT: Skin Bounce Light Desaturation is under PT: Sky Impact.
   - Both "Shading Frame Budget" rows are gone.
   - Textures / Rendering shows Textures Streamed at Once and Terrain Preload Distance (Tree and Bush Draw Distance is intentionally absent).
3. **Native / Auto:** every new row starts on Native / Auto, and its description appears once.
4. **Presets:** pick Performance, Balanced and Extreme in turn.
   - The new rows stay Native / Auto.
   - The other values are the same as RC5 (without the two budgets).
   - Changing any preset row switches Quick Preset to Off.
5. **Path Tracing:**
   - Scene Range 200 m: the scene still renders correctly.
   - Caustics: Ray-Traced Caustics On and Caustics Light the Scene On, then look at water in sunlight. Hair still looks right (Orange Hair Fix).
   - Fog Off in fog or rain: the reflections are clearer.
6. **Normal RT:** RTGI rows work as in RC5, and Fog in RT reflections works.
7. **Master Off:** every row greys out; turn it back On.
8. **Settings file:**
   - Set HBIL On (Normal RT), Textures Streamed at Once 32 and Terrain Preload Distance 200 m.
   - Change one URT row, quit the game, then compare `dx12user.settings` with your backup.
   - Expected: `UseHBIL`, `TextureInFlightCountBudget` and `TerrainReadAheadDistance` keep your old values (or stay absent).
   - Texture Quality is still your setting (e.g. Ultra+).
9. **Restart:** the URT values you chose are still selected, and they apply again.
