## Audit results
| Item | Result |
|---|---|
| Diagnostics kept | Startup and identity; tier; shader slots and identity; renderer transitions; Master; every CPU and RT control state; settings integrity (self-check, recovery, .bak/.corrupt); compatibility scan; every refusal with its reason. |
| Log bounds | Each line is written synchronously (survives a crash). 64 KB per session, +64 KB reserved for error lines, then further lines are dropped. Normal RT apply/release lines are de-duplicated within 30 s and capped at 48. Recreated every launch. |
| Shutdown | All URT state lives in the game process (CVar values, code patches, CameraCB carrier) and ends with it. Nothing is written at exit. The settings file is only ever replaced atomically (temp → flush → `ReplaceFileW`, `.bak`), so a kill mid-write cannot corrupt it. The "runtime stopped" path releases every owner when settings notifications are lost. |
| Settings safety | No INI writer is imported (asserted), so `dx12user.settings` is never written. Store tests: 12 scenarios under ASan/UBSan. Removed selectors (`PTShaderCompat`, `RTTreeShadowDistance`) are never read for any decision. |
| Installer cleanliness | No `dinput8.dll`, no legacy-named ASI, no ReShade add-on, no Beardmo files. The UAL licence ships with MAIN. MAIN = ASI-ONLY + loader + licence (asserted). |
| Reproducibility | Two-pass native build is byte-identical; both archives were packaged twice with identical hashes; rebuilding from the tag gives identical hashes. |
| Removed features stay removed | No layering, ReShade, Tree Shadow Distance or PT Shader Compatibility code or strings (asserted). Menu and locales are byte-identical to V4.3.1. |
| Tests | 27/27, including `compat_evidence_iwo` on the user's IWO 2.2.3 files. |
