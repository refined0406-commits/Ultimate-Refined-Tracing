# URT V5.2.0 CURATED PRIVATE RC1 — IN-GAME ACCEPTANCE CHECKLIST

**This is not a public release.** No gameplay, actual `dx12user.settings` integrity or Orange Hair Fix/Immersive World runtime compatibility has yet been independently validated for this build.

**Before installing:** Exit The Witcher 3. Copy `Documents\The Witcher 3\dx12user.settings` somewhere safe outside the game and Documents/Witcher 3 folder. Keep protected V5.1.0 MAIN/ASI and your private preferences for rollback. Choose exactly ONE installation ZIP (MAIN includes `winmm.dll`, ASI-ONLY uses your existing loader). Do not remove another mod's `dinput8.dll` or SharedUtils mod/DLC. Replace the old URT files via your usual installation method. Do not run the old R5 experimental build alongside this one.

1. **First launch and menu:** Options > Mods > Ultimate Refined Tracing should show Master and Quick Preset at top, CPU / Path Tracing / Ray Tracing / Texture / Streaming / Frame Generation white named headers; RT area has two subtle separators. The long labels must be readable and scrolling must reach all 49 controls. PT: Indirect-Light Compensation stays immediately below Hair Bounces. The four retired PT RTAO rows must NOT appear, and no Advanced page should exist.
2. **Protect the native graphics settings:** Before changing any native graphics menu settings, record their values (screenshots acceptable). With URT Master On, Off, Native/Auto, and after one game restart, confirm the game's native graphics-menu choices are unchanged. Watch the backup/current `dx12user.settings` for missing/zero-byte state. The game may legitimately rewrite the file on menu save, so compare **native graphics values** as well as file health, not only its SHA256.
3. **Persistence and presets:** With Master On, change PT Scene Range and a new RT setting in their correct rendering modes. Leave and reopen URT menu, then restart; values should persist. New additions must not unexpectedly remap Performance/Balanced/Extreme. Existing V5.1 preset assignments and manual-edit auto-Off on preset-controlled rows must behave as before. Master Off should release effective URT overrides without resetting native graphics settings.
4. **Renderer isolation:** Try the same PT-only change in normal RT and Raster: it must not affect them. RT-only changes must not affect PT/Raster. Confirm Native/Auto restores the effective native value after the requisite load/restart. Report visuals/FPS only from comparable scenes, not menu averages.
5. **Texture streaming:** Texture Memory Budget is an advanced engine value: changing it may require loading a save, and immediate memory-pool resizing is not proven. Return to Native/Auto if you see corruption, missing textures or instability. Test Texture Sharpness and Textures Streamed at Once separately.
6. **Compatibility:** Verify normal RT and PT hair using Orange Hair Fix RT+PT; verify Immersive World wind, grass/trampling, streaming/loading and in-game animation; switch gameplay to/from both renderers and reopen menus. Test Game Difficulty/Gwent Difficulty (protected crash hotfix). At least one 20–30-minute stability session with logs after initial smoke checks.
7. **Frame Generation: Keep Resources in Menus:** Leave Native/Auto for initial baseline. If later tested, compare menu exit frame times and tearing with and without the option. Use NVIDIA App Recommended (not the previously problematic beta Preset C), and confirm FG/Reflex/G-SYNC/V-Sync remains normal. Do not infer an FPS gain from installation or the WCC receipt alone.
8. **Collect only if anything fails:** `bin\x64_dx12\UltimateRefinedTracing.log`, `scriptslog.txt` if generated, and screenshots of the affected option and vanilla graphics menu. Do NOT share proprietary game executables or your personal settings file without redacting private data.

**Release gate:** Public V5.2.0 Nexus and GitHub uploads are not authorised until these gameplay checks pass, outstanding issues are fixed and private packages are reaudited. Rollback remains the protected V5.1.0 archives.
