# V5.2.0 RC7 - in-game acceptance checklist

Back up `Documents\The Witcher 3\dx12user.settings`. Install RC7 MAIN (or ASI-ONLY) over RC6.

1. **Other mods' menu file:** search your `mods` folder for `panel_ingamemenu.redswf`. It must exist only in `modRefinedTracing`.
   - If another mod (for example Mod Settings Menu Fix) has one too, tell me which one before judging the separators.
2. **Separators (the release blocker):** check that all 8 headings show `line | title | line`:
   - CPU
   - Path Tracing
   - Ray Tracing
   - RTGI: Quality
   - RTGI: Performance
   - RT/PT: Shared
   - Textures / Rendering
   - Frame Generation

   Check them:
   - at first opening;
   - while scrolling one step at a time down and up;
   - with Master Off and On;
   - after visiting another mod's page and the vanilla Graphics page;
   - after closing and reopening the menu;
   - after restarting the game.
3. **Caustics:** the PT: Caustics heading and its rows are gone. Path Tracing water looks as it does without URT.
4. **Tree and Bush Draw Distance:** it sits under Terrain Preload Distance.
   - Set 2.6, then load an area: distant trees and bushes are drawn further away.
   - Graphics > Foliage Visibility Range still shows your own level.
   - Restart and check it again.
5. **Native change while Tree is active:** change Foliage Visibility Range in the game's menu, leave the menu, then quit.
   - `dx12user.settings` now holds your new level for `FoliageDistanceScale`.
   - URT's value applies again after the restart.
6. **Settings file:** compare it with your backup. `FoliageDistanceScale`, `TerrainReadAheadDistance`, `UseHBIL` and `TextureInFlightCountBudget` keep your own values. Texture Quality is unchanged.
7. **Regression spot checks:**
   - Quick Presets work.
   - Master Off greys every row.
   - Hair looks right in RT and PT (Orange Hair Fix).
   - Immersive World vegetation and trampling still work.
