What the ASI does: it is a performance mod for Witcher 3 Patch 5.01 (ray/path tracing).
- It runs only inside witcher3.exe.
- It verifies the game executable's SHA-256.
- It reads the game's settings without ever writing them.
- It applies byte-verified in-process code patches, the standard technique for game mods.
- It stores its own settings and log file.

What the ASI does not contain:

- No networking APIs and no URLs or IP addresses.

- No process creation and no registry writes.
- No packing or obfuscation.
