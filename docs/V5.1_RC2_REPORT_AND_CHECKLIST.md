# V5.1.0-rc2 (private): change report, offline results, gameplay checklist

## Changes vs V5.1.0-rc1
* **Kept:**
  * RTGI: Performance Console Probe Grid
  * RT Reflections: Local Lights
  * RT Shadows: Local Light Shadows
  * RT Shadows: Foliage Detail
* **Removed entirely:** RTGI: Probe Ray Distance, RT Reflections: Texture Detail, RTAO: Foliage Detail. That covers their menu rows, strings, script and runtime. Old saved values for them are ignored.
* **Quick Presets:** the new rows are added to the existing single preset step. All 39 V5.0.0 preset assignments are unchanged.

  | | Performance | Balanced | Extreme |
  |---|---|---|---|
  | Console Probe Grid | On | On | Native / Auto |
  | Reflection Local Lights | Off | Off | Native / Auto |
  | Local Light Shadows | Off | 4 | Native / Auto |
  | Foliage Detail | Very Low | Low | Native / Auto |

* **Tooltips:** rewritten in all 18 languages, with "can improve FPS" wording. The Console Probe Grid tooltip says it only works with the game's RTGI on Performance, never changes graphics settings, and has no effect in Quality.

## Changed package files vs V5.0.0 (same in MAIN and ASI-ONLY)
The ASI, the menu XML, the 18 `.w3strings` files, `precompiled.rsblob` and the README. `winmm.dll`, the menu UI file and the licence are byte-identical. MAIN = ASI-ONLY + `winmm.dll` + licence.
