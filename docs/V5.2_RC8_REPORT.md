# V5.2.0 CURATED PRIVATE RC8: test report

**Change from RC7 (accepted in game):** Tree and Bush Draw Distance is permanently removed. Nothing else changed.

## What was removed

| Area | Change |
|---|---|
| Menu | The row is removed from Textures / Rendering and from the hidden URTExtended storage. Textures Streamed at Once and Terrain Preload Distance stay. |
| Runtime | The row is removed from the engine table (9 engine rows + FG). `FoliageDistanceScale` is never bound, read or written, and its save flag is never touched, so the game alone owns Foliage Visibility Range. A `URTX_TreeDistance` value saved by RC7 is ignored. No setting is reset or rewritten, so the player's chosen value stays as it is. |
| Localisation | The label, tooltip and its four unused option strings are removed in all 18 languages. |
| Script | Not recompiled. The RC6/RC7 compiled script (`0d39070a…`) is reused: its entries for the removed row are inert, and `menu_delta` proves that the menu equals the compiled menu minus the documented retired rows. |
