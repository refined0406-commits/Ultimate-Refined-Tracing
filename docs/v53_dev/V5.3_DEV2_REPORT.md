# Ultimate Refined Tracing V5.3.0 DEV2 (private): menu polish and tooltip clarity

This build is private and not for publication. V5.2.0 and V5.3.0 DEV1 remain the rollback checkpoints (git tags `v5.2.0` and `v5.3.0-dev1`, and their archives).

## What changed and what did not

DEV2 changes three kinds of data, all on the menu side:
- strings: the 18 `.w3strings` files;
- four option display names in the menu XML;
- the package README.

No setting value, option ID, row, order, Quick Preset entry or default changed. The script is unchanged.
- **Script:** `precompiled.rsblob` is the DEV1 receipt blob `2f3927cc…`. No recompile was needed, because tooltips and option labels are looked up by key at run time.
- **ASI:** byte-identical to DEV1 (`38745faa…`). Its log therefore still reports `5.3.0_DEV1_PRIVATE`.
- **Nine V5.3 engine-variable controls:** behaviour unchanged.

Compared with the DEV1 MAIN archive, exactly 20 entries differ:
- the README;
- `RefinedTracing.xml`;
- the 18 string files.

## Tooltips

All 54 adjustable controls have a rewritten tooltip in 18 languages. Ray-Traced Optimizations and the Quick Preset keep their existing text. Each tooltip follows this order:
1. **What it does:** what the setting changes, which way to adjust it, and the trade-off.
2. **Native / Auto:** a verified value (engine-registered default, RTGI tier value, or `gc.ini` 1800), or "chosen automatically by the game" / "the game's own value" where it is not proven.
3. **Performance class:** one fixed phrase per class:
   - may raise FPS;
   - CPU-limited FPS;
   - visual only;
   - visual fix with no measured FPS change;
   - varies by scene;
   - pop-in and loading hitches, not average FPS;
   - memory and occasional stutter, not average FPS;
   - loading smoothness, not average FPS;
   - Frame Generation menu memory.
4. **When it applies:** immediately, newly loaded areas, or after a game restart. The restart phrase appears only for the two RT acceleration-structure rows, which the engine reads once when ray tracing starts.

A few tooltips add one more piece:
- the CPU rows and RT/PT Fog add their renderer scope;
- the RTGI rows add "Needs Ray-Traced Optimizations = Auto".

Elsewhere the section heading already conveys the mode.

Wording such as "can", "may" or "varies" marks expectations. Measured claims are explicit ("no measured FPS change"). No tooltip promises an FPS gain.

**RT Acceleration Structure Build Batch Size:** says it is not an FPS setting and that lower is not automatically better. Smaller batches may smooth area-loading spikes, but new objects can join RT shadows and reflections slightly later. Native / Auto: 256. Applies after a game restart.

**RT Acceleration Structure Defragmentation:** lower values defragment more often, keeping VRAM tidier in long sessions at the cost of extra work and possible brief spikes. It does not raise FPS. Native / Auto: 30%. Applies after a game restart.

**Length:** each tooltip fits the larger of two bounds: the longest tooltip DEV1 already rendered in that language, or the English DEV1 maximum (386). Width is weighted, with CJK and Hangul characters counted as 2 units.

The full English text is in `docs/v53_dev/DEV2_TOOLTIPS_EN.txt`.

## In-game checklist (DEV2)

1. Install DEV2 MAIN over DEV1, or ASI-ONLY if you keep your loader. Load a save.
2. **RT: GI Alpha-Test Texture Detail:** it cycles Native / Auto → 4 → 6 → 7 → 8, with no "Urtx".
3. **Mesh Streaming Distance:** it shows 5 m / 20 m / 40 m.
4. **Master and the CPU rows:** On/Off in your language.
5. **RTGI rows:** they show "Native / Auto (128)" etc., and the probe limits have no commas.
6. **Skin Bounce Light Desaturation:** it shows 0.00 / 0.25 / 0.75 / 1.00.
7. **Tooltips:** hover several, especially the two RT Memory Management rows, a long RTGI row and CPU: Distant Trees. Check that the whole text fits the tooltip area without being cut off. If a language you use overflows, note which row.
8. **Saved values:** your existing values are kept, because only labels changed. Frame Generation is still the last section.
