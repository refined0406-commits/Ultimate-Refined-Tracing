Findings about the reference mods [exe + your install]:
- `AutoDiscardCount` is registered under `MetadataStore` and `RTConfigMaxBlasesInBatch` under `Rendering/RayTracing`, while the INIs (including the game's own `gc.ini`: `[Memory/GC] IdleFrameCount = 1800`, `AutoDiscardCount = 1000`) use other section names. Whether the INI loader still applies those two lines is unverified, so the tooltips quote no native number for them.
- URT writes the live values directly, so its rows work either way.
- The two RT AS values are read **once**, when ray tracing initialises:
  - they are copied into the AS configuration at `0x405af10/14` under the render-device start;
  - URT applies them as early as its worker can, before a renderer exists;
  - the log then states whether the AS manager is using them. If URT was too late, the values apply from the next start.
