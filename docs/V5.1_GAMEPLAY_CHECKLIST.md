# V5.1.0-rc1 private test: gameplay checklist

Install V5.1.0-rc1 MAIN over V5.0.0 (rollback: reinstall V5.0.0). Use Master On and Normal RT (not PT). Keep NVIDIA Frame Generation on Recommended, as before.

## A. Safety first (all new rows on Native / Auto)
1. FPS and visuals are identical to V5.0.0, in RTGI Quality and in Performance.
2. Change Game Difficulty and Gwent Difficulty. Nothing crashes.
3. The URT menu shows the 7 new rows at the end, with tooltips. They grey out with Master Off.
4. PT > Normal RT > Raster > PT works, and the PT FPS (Geometry Bounces 1 vs 4) is unchanged.
5. Orange Hair Fix and Immersive World still work.

## B. FPS A/B (one control at a time)
Use the same save, spot and camera, and stand still about 10 s per reading. Record:
* average FPS;
* whether the GPU is at about 97–100% (GPU-bound) or lower (CPU-bound);
* what you see change.

Return each control to Native before testing the next.

| 1 | RTGI: Performance Console Probe Grid **On** | RTGI **Performance**; open field and village | A one-time brief pause when switched; then FPS vs Native |
| 2 | RTGI: Probe Ray Distance 64 m, then 32 m | Both RTGI modes; open countryside | FPS; indirect light from distant hills/buildings |

## C. Console Probe Grid lifecycle (RTGI Performance)
1. Turn it **On**. You should see one brief pause, and the log shows "console probe grid active".
2. Switch RTGI to Quality and back to Performance. It re-applies by itself (one more brief pause).
3. Save, quit to the menu, load the save. Still active.
4. Turn it **Off**, or set Master **Off**. One brief pause, and the log shows "native RTXGI tier restored".
5. Restart the game with it On. It becomes active shortly after loading into the world.

## D. Logs
* `UltimateRefinedTracing.log` should include:
  * "Normal RT performance controls ready"
  * "RTGI Performance console probe grid ready"
  * "runtime tier FULL"
* There should be no "invalid" or "gave up" lines.
* `scriptslog.txt` should show no new errors.
* Optional: search `dx12user.settings` for `BalanceModeRT` and `ProbeMaxRayDist`. Neither should appear.

Please send the FPS table (B), any visual problems, and both logs.
